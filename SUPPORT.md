# Support

- **Bug reports:** use the [bug report form](https://github.com/aspire488/kairo-email-intelligence/issues/new?template=bug_report.yml).
- **Feature requests:** use the [feature request form](https://github.com/aspire488/kairo-email-intelligence/issues/new?template=feature_request.yml).
- **Questions and ideas:** start a [GitHub Discussion](https://github.com/aspire488/kairo-email-intelligence/discussions).
- **Security issues:** follow [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities publicly.

Before opening a request, search existing issues and discussions. Include the KAIRO version or commit, environment, expected behavior, actual behavior, and minimal reproduction steps. Redact inbox content, personal information, and credentials.
